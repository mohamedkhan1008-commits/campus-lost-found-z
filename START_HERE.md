## 🎯 5-MINUTE QUICK START

### Step 1: Open PowerShell
```powershell
cd "c:\Users\eve1\Documents\campus lost found\backend"
```

### Step 2: Install backend
```powershell
npm install
```

### Step 3: Start backend
```powershell
npm start
# You should see: "Server running on http://localhost:5000"
```

### Step 4: Open NEW PowerShell window
```powershell
cd "c:\Users\eve1\Documents\campus lost found\frontend"
```

### Step 5: Start frontend
```powershell
python -m http.server 8000
# OR right-click index.html in VS Code -> "Open with Live Server"
```

### Step 6: Open browser
```
http://localhost:8000
```

✅ **You're done! Application is running!**
